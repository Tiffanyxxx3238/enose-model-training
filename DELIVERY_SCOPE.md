# PineNose exhibition delivery scope

This branch provides a code-focused delivery view for the October 2026 exhibition. The `evaluation/` research/audit directory is intentionally excluded from this **delivery branch only** to keep the deployment package and exploratory reports separate. It remains available, unchanged, on [`main`](https://github.com/Tiffanyxxx3238/enose-model-training/tree/main/evaluation).

This exclusion is **not** evidence that the reported 42.4% strict LOGO accuracy is invalid, nor a new accuracy claim. The earlier reported 86% used evaluation conditions that have not yet been established as comparable. The repaired Raspberry Pi measurement pipeline has not yet had its independent field classification accuracy established from ground-truth-labeled fruit.

No deployed code, ExtraTrees model, AIR configuration, or Raspberry Pi runtime was changed by this branch. This is a **source-code delivery view**, not a validated deployment release. Maintain the current working Raspberry Pi installation and verify runtime/scan evidence separately.
