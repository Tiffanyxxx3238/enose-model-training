Operation Guide

系統使用操作說明

請依照下列流程操作，以確保檢測程序順暢且辨識結果完整呈現。
01

氣味成熟度辨識流程

  1. 確認 Arduino Mega 2560、氣體感測器與 Raspberry Pi 已完成連接。
  2. 進入「氣味成熟度辨識」分頁，先執行空氣校正以建立環境基準值。
  3. 依展示需求選擇快速檢測、標準檢測或完整檢測模式。
  4. 完成量測後，系統將自動顯示鳳梨成熟階段與判讀結果。
02

照片品種辨識流程

  1. 確認電腦端照片模型服務已啟動，且 Raspberry Pi 與電腦位於同一網路。
  2. 進入「照片品種辨識」分頁，上傳待辨識之鳳梨照片。
  3. 系統會先判斷是否為鳳梨，再進行品種分類與信心分數計算。
  4. 辨識完成後，畫面將顯示預測品種、信心分數與相關判讀訊息。
03

展示與維護注意事項

  • 氣味檢測前請盡量保持量測環境穩定，避免外部氣味干擾。
  • 照片辨識建議使用光線清楚、主體明確、背景不過度雜亂之圖片。
  • 若分頁內容未正常載入，請確認對應 Flask 服務與連接埠是否已啟動。
  • 若照片辨識無法回傳結果，請檢查電腦端模型 API 是否仍在執行。
